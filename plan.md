# Multi-Channel Notification & Automation System: Development Plan

## 1. Executive Summary & Codebase Audit

The repository currently contains experimental proof-of-concept scripts for student notifications and alerts:

1. **`import pywhatkit.py`**:
   - Sends individual WhatsApp messages via `pywhatkit` browser launch and `pyautogui.press("enter")`.
   - Hardcoded grade reports (Course: Comp 304 Compiler Design).
   - Relies on OS-level UI automation, which is prone to timing issues, resolution differences, and window focus loss.

2. **`sen mail in formatd.py`**:
   - Sends retro-styled HTML emails via Gmail SMTP (`smtp.gmail.com:587`).

3. **`PyWhatKit_DB.txt`**:

## 3. Phased Roadmap

### Phase 1: Security Hardening & Project Standardization
- **Credential Sanitization**:
  - Revoke exposed Google App Password.
  - Setup `.env` configuration using `python-dotenv`.
  - Add `.gitignore` to prevent secret leaks and repository pollution.
- **Project Structure Setup**:
  ```
  whatsapp-automation/
  ├── src/
  │   ├── core/           # Config, logging, models
  │   ├── services/       # Email & WhatsApp delivery providers
  │   ├── templates/      # HTML and text templates (Jinja2)
  │   └── utils/          # Phone normalization, validators
  ├── data/               # Sample CSVs / Excel files
  ├── tests/              # Unit & integration tests
  ├── .env.example
  ├── requirements.txt
  └── main.py             # CLI entry point
  ```

### Phase 2: Data Ingestion & Templating Engine
- **Recipient & Grade Modeling**:
  - Validate student records using `pydantic` (ID, Name, Phone, Email, Courses, Scores).
  - Ingest from Excel (`.xlsx` via `openpyxl`) and CSV files.
  - Automatic international phone number normalization (e.g. converting `010xxxxxxxx` to standard `+2010xxxxxxxx`).
- **Dynamic Template Management**:
  - `Jinja2` rendering for both:
    - HTML responsive emails.
    - WhatsApp formatted text messages (bold, italic, monospace, bullets).

### Phase 3: Delivery Providers & Automation Engines
- **Email Channel**:
  - Production-ready SMTP client with TLS, customizable headers, attachment support (e.g., student grade slips or PDF reports), and error recovery.
- **WhatsApp Channel Options**:
  - **Option A (Meta Cloud API)**: Cloud-native, zero-browser dependency, reliable delivery receipts.
  - **Option B (Browser Automation via Playwright)**: Automated WhatsApp Web sessions with saved profiles (no manual QR scan on every run, headless or headed, robust element selectors).
  - **Option C (Refactored PyWhatKit)**: Improved delay handling, window focus verification, and retry logic.

### Phase 4: Anti-Ban, Rate-Limiting & Audit Tracking
- **Anti-Ban Throttling**:
  - WhatsApp flags numbers sending bulk messages in rapid succession.
  - Implement randomized intervals (e.g., 8–20 seconds) and configurable batch windows.
- **Audit Logging**:
  - Store message logs, delivery statuses, timestamps, and error traces in SQLite or structured JSON logs instead of plain text.
  - Dead-letter queue for failed deliveries with retry capability.

### Phase 5: User Interface & CLI
- **Command-Line Interface**:
  - Interactive terminal using `rich` and `typer` or `click`:
    - `python main.py send --file data/grades.xlsx --channel wa`
    - `python main.py send --file data/grades.xlsx --channel email`
    - `python main.py test-connection`
- **Optional Web Dashboard**:
  - Simple Streamlit or FastAPI web UI for drag-and-drop file uploads, previewing messages, and tracking live dispatch progress.

### Phase 6: Automated Testing & Packaging
- Unit tests for data parsing, template rendering, and phone number sanitization.
- Mock tests for email and WhatsApp dispatchers.
- Automated test runs using `pytest`.
